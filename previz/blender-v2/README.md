# 좀비 인 동탄 EP01 · Blender 프리비즈 v2

- 현재 웹소설과 22장면 콘티를 기준으로 제작: 107컷 / 151초 / 1280×720.
- Blender 5.2.2 / 12fps 동작 및 카메라 키 / 최종 MP4 24fps.
- 아빠 제레미는 화면 밖에 있으며 기침과 닫힌 문으로 병세를 전달한다.
- 릴리·서진·소형 그레이하운드 루나가 약을 구하고, 보라색 삐에로 슬롯 7번으로 서진의 슈트가 조립된다. 거미줄·줄타기 탈출, 슈트 회수, 약 확인, 결과를 숨긴 두 번째 룰렛으로 끝난다.

## 파일

- `EP01_블렌더_프리비즈_v2.mp4`: 한글 대사·촬영 지시 자막과 효과음이 합쳐진 영상.
- `EP01_151초_프리비즈.blend`: 수정 가능한 인물·환경·소품·107개 카메라와 타임라인. 효과음은 파일 안에 포함되어 있다.
- `EP01_전체장면.jpg`: 22장면 전체 미리보기.
- `EP01_대사.srt`: 대사 자막.
- `audio_timeline.json`: 실제 효과음 시작 시각·음량.
- `build_scene.py`, `primitives.py`, `render.py`, `assemble.py`: 재생성용 소스.

## 수정 방법

Blender 파일을 열고 카메라 보기에서 타임라인을 재생한다. 타임라인 마커가 컷별 카메라를 전환한다. LILY, JIN, LUNA 및 CAM 이름의 오브젝트를 통해 동선과 구도를 수정할 수 있다. 키는 12fps로 구워져 있어 큰 동선 변경은 build_scene.py를 수정한 뒤 다시 생성하는 편이 쉽다.

최종 영상의 한글 그래픽·대사 자막은 assemble.py에서 합성한다. 상세 얼굴, 실제 라크몽의 정밀 복원, 옷감·충돌 시뮬레이션 및 최종 VFX는 포함하지 않는 단순 3D 동작 프리비즈다. 카메라 지시의 복잡한 액션은 단순 이동과 포즈로 표현한다.

## 소리

BGM과 새 대사 녹음 없이 효과음 및 한글 대사 자막을 사용했다. 기존 룰렛·달리기·간판 충돌을 재사용하고, Agent Audio로 슈트 조립·거미줄·호숫가·전화 알림·기침을 새로 만들었다. 효과음은 영상에 실제 합성했으며 전체 수동 청취 검수는 수행하지 않았다.

## 재생성

상위 폴더의 EP01_압축_씬데이터.json이 필요하다. Blender 백그라운드 모드로 build_scene.py를 실행한 다음 저장된 blend와 render.py로 프레임을 렌더링한다. Python(Pillow, numpy)으로 assemble.py를 실행하면 FFmpeg를 통해 자막·효과음 포함 MP4가 만들어진다. index.html은 MP4 및 장면별 미리보기와 함께 배포한다.

## 확인 결과

MP4 151.000초 / H.264 1280×720 / 24fps / 3,624프레임 / AAC 오디오. 전체 FFmpeg 디코드 오류 없음. 22장면 대표 프레임을 확인했다. Blender 타임라인은 1~1812프레임, 107개 컷 마커 및 1812프레임 효과음 트랙을 포함한다.
